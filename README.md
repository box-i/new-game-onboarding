# 新游接入全流程管理 (new-game-onboarding)

游戏平台PM新游接入 Claude Code Skill。覆盖从项目首次对接 → 版署审核 → 对外测试 → 正式上线的完整工作流，自动生成跟进文档和任务清单。

## 安装

```bash
npx skills add {你的GitHub用户名}/new-game-onboarding -y
```

## 使用

```
/new-game-onboarding <gate或游戏名> [当前阶段]
```

示例：
- `/new-game-onboarding m2k8` — 自动解析 gate，追问阶段
- `/new-game-onboarding m2k8 不付费对外测试` — 指定阶段，跳过阶段询问

## 功能

| 阶段 | 输出 |
|------|------|
| 第一步 | Gate 编码解析（22 种发行方案 × 16 个地区码） |
| 第二步 | 判断项目阶段，跳过已完成环节 |
| 第三步 | 8 模块逐节引导收集项目信息 |
| 第四步 | IMS + 短信白名单后台配置清单 |
| 第五步 | 虚拟充值处理 |
| 第六步 | 账号类（12 项）+ 客服类（4 项）功能验证清单 |
| 第七步 | 充值接入清单 + 8 项验收清单 |
| 第八步 | 完整跟进文档 → 自动保存为 .md |

## 适用场景

- 端游 / 手游
- 国服 / 海外
- 自营 / 代理
- MMO / SLG / 回合制 / 换皮
